# Changelog

All notable changes to Lume Fashion Commerce are documented here.

## [0.1.1] - 2026-06-09

### Changed

- Updated development dependencies through the Dependabot maintenance PR.

## [0.1.0] - 2026-06-09

### Added

- UX-first fashion commerce experience with home, product listing, product detail, cart, and checkout.
- URL-shareable filters, accessible search suggestions, size guide, product JSON-LD, and static GitHub Pages export.
- Playwright coverage for the critical purchase flow on desktop and mobile.
- CI, CodeQL, Dependabot, security policy, contribution templates, and public demo.

### Notes

- This project supports the portfolio as the product/UX and e-commerce sample.
